# McGreen Creative Lab

An original, research-led creative intelligence knowledge base for graphic design, interior and spatial design, video, motion, VFX, and AI-assisted production.

## Principles

- Research upstream projects; do not clone their skills or distinctive content.
- Record source URLs, licenses, versions, dates, and provenance.
- Write McGreen methods independently and validate them through practical tasks.
- Separate verified facts, observations, synthesis, and hypotheses.
- Respect copyright, licenses, privacy, safety, and attribution obligations.

## Structure

- `CORE/` — identity, principles, governance
- `RESEARCH/` — upstream source registry and research method
- `KNOWLEDGE/` — original domain knowledge
- `SKILLS/` — reusable original skills
- `WORKFLOWS/` — production processes
- `QUALITY/` — critique and validation

## Working cycle

Frame → Research → Interpret → Concept → Prototype → Critique → Produce → Validate → Record

This repository does not retrain model weights. It is a persistent reference base for ongoing work.
